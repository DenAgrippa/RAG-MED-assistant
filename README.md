Итоговая работа представляет собой систему для обработки клинических рекомендаций (КР), их структурирования, классификации по смысловым категориям и дальнейшего использования в retrieval-generation пайплайне.

## 1. Источники данных

Клинические рекомендации загружаются только в формате HTML. Парсинг выполняется с использованием Playwright и BeautifulSoup.
Пользовательские документы принимаются в формате HL7/CDA и используются в уже заданной структуре без отдельного этапа текстовой предобработки.

## 2. Предобработка и разбиение

Текст клинических рекомендаций очищается и классифицируется по трём категориям:
– симптоматика
– назначение лечения
– неопределённые фрагменты (fallback)
Классификация выполняется на основе регулярных выражений и списков ключевых слов. После классификации текст разбивается на чанки по стоп-символам.

## 3. Формирование векторных представлений

Каждый чанк кодируется моделью FRIDA. Вектор сохраняется вместе с категорией и метаданными в векторное хранилище.

## 4. Обработка пользовательского запроса

Входной текст запроса классифицируется по тем же категориям. Далее выполняется retrieval:
– сначала выбираются чанки той же категории,
– при нехватке совпадений подбор расширяется.

## 5. Augmentation и генерация ответа

Пользовательский запрос и найденные чанки объединяются в системный prompt, после чего LLM формирует итоговый ответ.
